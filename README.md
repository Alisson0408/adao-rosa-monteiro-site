# Adão Rosa Monteiro — Site oficial

Site do pianista, compositor e intérprete **Adão Rosa Monteiro**.

## Páginas
- `index.html` — página principal (contratação, agenda, formatos, história, trajetória)
- `galeria.html` — Galeria & Shows (fotos, vídeos ao vivo e apresentações no YouTube)
- `musical.html` — Musical Sebastiana (tributo familiar e vídeos do canal)

## Arquivos
- `styles.css` — visual de todas as páginas
- `script.js` — WhatsApp, formulário, players, agenda e links do Musical Sebastiana
- `galeria.js` — lista de fotos e vídeos da galeria
- `musical.js` — lista de vídeos do canal Musical Sebastiana
- `assets/` — vídeos, capas e fotos
